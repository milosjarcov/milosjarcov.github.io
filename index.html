Full-stack web app

Pickup Hoops

Find and join pickup basketball games at real courts around Montréal.

React · Vite · Leaflet · MapLibre · FastAPI · SQLAlchemy · PostgreSQL

View source↗

It starts from the map.

Seven real Montréal parks are seeded into the database with their coordinates and drawn on the map. Pick a court and it opens in the side panel, with its runs and who's playing.

See who's playing, then post a run or join one.

A run has a court, a start time, a skill level and a player limit. Anyone can look around without an account. Joining or posting asks you to sign in, or to continue as a guest in one tap. Passwords are hashed with bcrypt, and the API issues a JWT for the requests that need one.

The rules live in the API.

The FastAPI backend enforces them on every request, so no client can break them: runs must start in the future, full runs can't be joined, and only the host can cancel.

Four tables behind it.

Users, courts and runs, plus a join table that links players to the runs they've joined. SQLite while developing, PostgreSQL in production.

SkyWatch YUL

A live flight tracker for the sky over Montréal, built on real ADS-B data from the OpenSky Network.

React · Vite · Leaflet · MapLibre · FastAPI · OpenSky REST API

View source↗

Every plane, the way a controller sees it.

Each plane carries a data block like on an air traffic control screen: callsign, altitude in hundreds of feet, and ground speed. New data arrives every 15 seconds, and in between every plane keeps moving along its reported track, so the map never freezes.

A side view, lined up with the map.

Under the map, each plane sits at its altitude, directly below its spot on the map, even while you pan and zoom. Drag the amber floor to hide low traffic, or scrub back through the last ten minutes.

The whole trick is one function.

Every browser asks the FastAPI backend, never OpenSky directly. On each request the backend decides:

  • FreshAsked OpenSky less than 15 seconds ago? Return the snapshot.
  • StaleOlder than that? Fetch a new one from OpenSky.
  • DownOpenSky unreachable? Keep serving the last one and wait 15 seconds before retrying.
  • At onceTwenty requests in the same instant? The lock lets one call OpenSky, and the rest reuse its answer. A test checks exactly this.

One call to OpenSky every 15 seconds, no matter who's watching.

Anonymous OpenSky access allows roughly 400 calls a day. Since everyone shares one snapshot, more viewers means more requests to the backend, not more calls to OpenSky. Try it:
