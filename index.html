Pickup Hoops↗

React · Vite · FastAPI · SQLAlchemy

A full-stack app for finding and organising pickup basketball games in Montréal.

Register, browse courts on a Leaflet map, and post a run with a time, skill level, and player limit. Players can join or leave runs.

The backend uses four tables: users, courts, runs, and signups.

Skywatch YUL↗

React · MapLibre · FastAPI · OpenSky

A live map of aircraft over Montréal. It polls the OpenSky Network REST API and plots the positions reported by each aircraft's ADS-B broadcast.

A 15-second backend cache reduces requests to OpenSky and keeps the last snapshot available if the API is unreachable.
